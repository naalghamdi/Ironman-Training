# Mallorca 70.3 Training Dashboard

A standalone, mobile-friendly IRONMAN 70.3 Mallorca training dashboard.

## Publish with GitHub Pages from an iPad

1. Open GitHub in Safari and sign in.
2. Create a new **public repository**, e.g. `mallorca-703-dashboard`.
3. Upload all files in this folder to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site.
8. Open the Pages URL in Safari.
9. Tap **Share → Add to Home Screen**.

The dashboard stores edits, workout status, settings, and checklist progress in the browser's local storage.

The hosted HTTPS version is preferable to opening `index.html` directly from Files because Safari handles JavaScript storage and app-like behavior more reliably.
